# Agentation — Visual Feedback & UI Annotation

Agentation (`agentation` on npm, GitHub: `benjitaylor/agentation`) is a visual feedback toolbar for AI coding agents in React applications.

## Key Capabilities:
1. **Interactive Point-and-Click Annotation**: Users can hover and click any DOM element on the screen to highlight layout or styling issues.
2. **Selector & Text Extraction**: Captures CSS selectors, DOM paths, and exact text elements for accurate AI bug fixing.
3. **Integrated Component**: Rendered via `<Agentation />` in `src/App.tsx`.
